4. Perguntas respondidas
Progressão salarial por nível de experiência (EN, MI, SE, EX).

Comparação da progressão entre cargos principais (Data Analyst, Data Scientist, Data Engineer).

Diferença salarial entre modalidades de trabalho (On-site, Remote, Hybrid).

Se o trabalho remoto compensa em diferentes níveis de experiência.

5. Principais conclusões
Entry-level apresenta salários significativamente menores em todas as modalidades.

Senior-level e Executive-level concentram os maiores salários, com destaque para cargos de Data Scientist.

O trabalho remoto tende a pagar mais em níveis intermediários e seniores, mas a vantagem varia conforme o cargo.

6. Como rodar o projeto localmente

bash
pip install -r requirements.txt
Execute o script principal:

bash
python main.py
Os resultados e gráficos serão exibidos no console e/ou salvos em arquivos .csv e .png.
